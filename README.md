# VROX — Autonomous AI Agent

> Developed for **Data Alchemy 4.0** during **graVITas '26**, the annual techno-management fest at **Vellore Institute of Technology (VIT), Vellore**. Theme: *Driven by Innovation | Anchored in Sustainability*.

## 🚀 Overview
**VROX** is an interactive AI Agent interface and modular learning pipeline built to explore agentic workflows, LLM orchestration, structured prompt engineering, and execution loops. 

---

## 📂 Repository Structure

This repository is structured into progressive engineering sessions alongside the core web agent implementation:

* **`index.html`** — The frontend interactive web user interface for VROX.
* **`session_1_foundations.ipynb`** — LLM API integration, structured prompting, and foundational generation[cite: 3].
* **`session_2_agent_loop.ipynb`** — Implementation of the core Observe → Think → Act (ReAct) agent loop and tool calling[cite: 3].
* **`session_3_memory_planning.ipynb`** — Context retention mechanisms, short/long-term memory management, and multi-step task decomposition[cite: 3].
* **`session_4_frameworks_project.ipynb`** — Integration of agent frameworks and final project packaging[cite: 3].
